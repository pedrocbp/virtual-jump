# Segurança dos dados — respostas planejadas

Estas respostas correspondem ao código atual da versão 1.0.0. Revise novamente sempre que adicionar anúncios, analytics, login, nuvem, compras ou qualquer SDK externo.

## Coleta e compartilhamento

- O app coleta ou compartilha algum dos tipos de dados exigidos? **Não**.
- Dados são criptografados em trânsito? **Não aplicável**, pois não há transmissão.
- Usuários podem solicitar exclusão dos dados? **Não há dados em servidor**. Os dados locais podem ser apagados em **Configurações > Reiniciar meu progresso** ou pela desinstalação.

## Declarações relacionadas

- Anúncios: **Não contém anúncios**.
- Compras no app: **Não**.
- Conta de usuário: **Não existe**.
- Acesso restrito/login para revisão: **Não**.
- Permissões: somente `VIBRATE`, usada para feedback tátil opcional.
- Internet: permissão desativada.
- Backup de dados do Android: desativado no preset de exportação.

## Dados armazenados apenas no aparelho

Progresso, recordes, tempos, medalhas, tentativas, mortes, preferências de áudio/tema e skin selecionada são salvos localmente. Eles não saem do aparelho e, segundo a definição atual do formulário, não constituem coleta pelo desenvolvedor.
